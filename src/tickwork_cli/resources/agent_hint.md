### Tickwork local tasks

Use `tickwork-task-management` for this device's scheduled or manual commands. Discover the JSON contract with `tickwork --help` and subcommand help. Preview configuration writes and apply the actual plan only when authorized. Manual tasks have no native deployment; new scheduled tasks stay paused. Follow returned `follow_up` entries according to their authorization requirements: creation is not execution permission, and testing never automatically resumes a schedule. Verify this run's result, logs and expected artifacts. Preview `tickwork upgrade`, confirm its current plan when authorized, and query the returned operation with `agent upgrade-status` until completion. Use `task cleanup` for previewed history maintenance. Upgrade updates the package and registered Agent resources without enabling tasks or deploying them on other devices.
